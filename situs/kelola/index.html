Masuk pengelola

Halaman ini untuk tim yang mengunggah warta. Tempel kunci pengelola sekali saja; perangkat ini akan mengingatnya.

Belum punya kunci?
  1. Masuk ke GitHub dengan akun pemilik situs, lalu buka halaman pembuatan token.
  2. Token name: misalnya “Kelola warta”. Expiration: pilih masa berlaku yang diinginkan.
  3. Repository access → Only select repositories → pilih repo situs.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Klik Generate token, salin, lalu tempel di kotak di atas.

Kunci ini seperti kata sandi: bagikan hanya ke sesama pengelola.

Terbitkan baru

Apa yang mau diterbitkan?

Folder harus dibagikan ke “Siapa saja yang memiliki link”. Foto tetap tersimpan di Drive: flipbook menampilkan versi ringan, dan jemaat mengunduh JPG aslinya.

Sedang diterbitkan

  1. Mengunggah ke server
  2. Mengubah menjadi flipbook (biasanya 1–3 menit)
  3. Menayangkan di situs
